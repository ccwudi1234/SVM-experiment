# 决策树实验复现说明

进入仓库的 `决策树训练/` 目录按顺序运行，命令会更新图表与结果；不要同时运行多个报告生成任务。

```powershell
python 源代码/decision_tree_project/main.py
python 工具/refine_experiments.py
python 工具/check_100_percent.py
python 工具/build_report.py
```

公开仓库附有已生成的核查版报告。若需重新生成 Word，先将课程提供的 `实验报告模板2026.docx` 放到 `模板与要求/` 下。若需使用提交打包脚本，也请从原实验工作区复制项目约定 `AGENTS.md` 到当前目录。

主实验依赖见源代码目录 requirements.txt；本次报告和本地预览实际依赖版本见 requirements-report.txt。预览脚本需要 Windows 和已安装的 Microsoft Word；它不属于训练模型的前置依赖。报告输出为 实验报告/决策树实验报告-复现核查版.docx，分析完善版保留。封面的课程、系别、专业、年级、学号、姓名、指导教师及学年学期由本人核实填写。

```powershell
python 工具/render_word_local.py 实验报告/决策树实验报告-复现核查版.docx --output-dir "$env:TEMP/decision_tree_report_review"
```

测试集用于最终评价；深度剪枝曲线为训练部分内部验证；阈值曲线为验证集，冻结阈值后报告测试代价。统一按有毒概率大于等于阈值分类，概率恰好0.5归有毒类。主实验与补充实验CV均为五折分层、shuffle=True、random_state=42，编码器每折独立拟合；扩展实验也在各自用于拟合模型的训练样本上拟合编码器。

特征数量曲线属于探索性分析，不能直接将测试曲线用于最终选参。重复标签噪声实验的标准差仅表示固定划分下噪声位置和模型种子的变化。报告中的手写C4.5为简化增益率实现。

打包脚本保留原始数据、模型源码、选定Word报告，并加入复现工具、结果和模板；不会读取或打包其他AI工具专用目录。示例姓名学号必须替换为本人真实信息，勿原样提交。

```powershell
python 打包提交.py --major-class 专业班级 --student-id 学号 --name 姓名 --report 实验报告/决策树实验报告-复现核查版.docx
```
